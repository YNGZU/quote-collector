# Quote Collector 2.0 — patch notes

## Новое

- Компактное отображение длинных цитат с кнопками «Show more / Show less».
- Импорт библиотеки из JSON-файла в отдельной вкладке, совместимый с Firefox-подобными браузерами и debug-установкой.
- Избранное: добавление заметок в избранное и фильтр избранных заметок.
- Копирование цитаты вместе с названием и URL источника.
- Сортировка заметок: Newest, Oldest, A–Z и Favorites.
- Счётчик библиотеки внутри popup и индикатор `Showing X of Y`.
- Единая зелёная focus-обводка для поля поиска и элементов управления.
- Отдельные релизные архивы для Firefox и Chromium/Opera.

## Исправления

- Улучшена совместимость Firefox-сборки с требованиями Firefox Add-ons.
- Убраны небезопасные динамические HTML-присваивания из Firefox-сборки.
- Импорт JSON больше не зависит от жизненного цикла popup.

## Важно

Версия 2.0 использует локальное хранилище браузера. Данные не отправляются на сервер.
